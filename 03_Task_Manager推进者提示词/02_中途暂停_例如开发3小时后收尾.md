# 用户主动要求中途暂停 / 3 小时后收尾

```text
【Task Manager｜用户主动要求暂停本工作时段】

这是用户主动发出的 timebox pause，不是你自行决定停止。

先不要创建新的非必要 Dispatch。

1. 检查 active Task / Dispatch / Worker。
2. 能安全到达当前 Dispatch 边界则完成并 worker_done。
3. 不能安全完成则记录真实状态，不伪造 PASS / Evidence / CLOSED。
4. Persistent Worker 记录 session / context scope / health。
5. 立即 Capture 本时段产生但尚未记录的 Learning Events。
6. 对已发现可复用 Candidate 只记录 / request-promotion；不要为了赶收尾越权直接改 template。

更新允许写的：
- HANDOFF.md
- SCHEDULING_NOTES.md
- TASK_PRIORITY.md

HANDOFF 必须记录：
- Stage / Commit / Worktree
- Remaining P0
- Current Goal
- Task / Dispatch / Worker / Mode
- Persistent Session（如有）
- Last Evidence
- Open Human Gates
- Open Learning Event IDs
- Pending Promotion IDs
- PARTIAL Promotion IDs
- Current Blocking
- Next Single Action
- Relevant Files
- Git status

Continuation Contract：
current_p0_status = 当前真实状态
stop_requested = true
stop_reason = EXTERNAL_BLOCKER
blocking_evidence = "trusted user requested timebox pause"

注意：
这是用户来源的本次暂停证据，不允许你以后自行复制这个理由停下来。

输出一屏以内的下次恢复入口，然后停止。
```


## Trusted User Pause

这条“本工作时段暂停”是用户明确外部控制，不是 Task Manager 自己决定先停。

可信用户交互边界应形成 trusted session pause 状态，Continuation Guard 返回：

```text
SUSPEND_ALLOWED
requires_handoff = true
```

Task Manager 无权伪造。
